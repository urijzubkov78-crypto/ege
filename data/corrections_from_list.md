# Обновления по словарику

- эксперимент: Экспер...мент → экспер...мент
- сентиментальный: Сент...ментализм → сент...ментальный
- фломамстер: фл...мастер → фл...мамстер
- генеалогическое: ген...алогической (дерево) → ген...алогическое
- Ситуация: с...туация → С...туация
- исполинский: Исп...линский → исп...линский
- Окаймлять: ...к...ймлять → ...каймлять
- коричневый: К...ричневый → к...ричневый
- реставрировать: р...ст...врировать → р...ставрировать
- парадокс: п...р...докс → п...радокс
- мародер: мар...дёр → мар...дер
- винегрет: в...н...грет → в...негрет
- Оппонент: опп...нент → Опп...нент
- учреждение: Учр...ждение → учр...ждение
- изощренный: из...щрённый → из...щренный
- Аккомпанировать: акк...мпанировать → Акк...мпанировать
- Апелляция: ап...лляция → Ап...лляция
- антагонизм: ант...г...низм → ант...гонизм
- батальон: Б...тальон → б...тальон
- Фельетон: фель...тон → Фель...тон
- федерация: ф...д...рация → ф...дерация
- дезертир: д...з...ртир → д...зертир
- Аккомпанемент: акк...мпанемент → Акк...мпанемент
